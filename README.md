Vice Light Studio — a GTA 6 cover maker. Pick real photos, arrange them in a
multi-panel grid, grade them with a unified Vice City sunset/neon grade, set a
giant condensed title over a retro sun + skyline band, and export the cover as
a 1080×1080, 1080×1350, or 1920×1080 PNG. Four layouts, four grades, halftone
and posterize finishes, ten sample photos, drag to pan and scroll to zoom.

## Run it

```sh
node main.ts
```
